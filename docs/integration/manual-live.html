XXLive adapter (เฟส B) — หน้าที่พอร์ตแล้วเรียก REST จริงแทน mock

หลังตัดสินใจ "backend = REST API เท่านั้น ไม่มี Tomcat/BFF" (ADR-001) servlet ของ Java (/board/*, /rvapi, /dashboardapi …) ที่เคยถือ token ใน HttpSession แล้วเรียก triplesale-service ถูกแทนด้วยโค้ดในเบราว์เซอร์: หน้ายังเรียก URL เดิม (สัญญา <หน้า>-backend.ts) แต่ live backend (<หน้า>.live.ts) ตอบด้วย Response ที่ประกอบจากการเรียก REST ผ่าน HttpClient ของแอป (Bearer interceptor, 401 = session หมด, API log) และทำสิ่งที่ servlet เคยทำทั้งหมด: ตรวจ role, ใส่ param/default/clamp, เรียก upstream ตามลำดับ/encoding เดิม, แกะ envelope, ทำความสะอาด/แปลภาษา/เปลี่ยนชื่อ field, map status, ข้อความ/สถานะของทุกทางผิดพลาด

วิธีพิสูจน์

  • spec ต่อ route ด้วย fakeRest: URL/query ที่ยิง REST (ลำดับ, encoding, param ว่างไม่ส่ง), role gate, ทุกทางผิดพลาด (non-200, ไม่ใช่ JSON, ไม่มี result, status 0), การแปลง/ทำความสะอาด, TH/EN, default/clamp — expected มาจากการอ่านโค้ด Java ไม่ใช่จากการรันโค้ดของเรา
  • node tools/compare/run.mjs <หน้า> --live: แอปรันแบบ mock:false ผ่าน proxy แบบ same-origin ไปยัง REST จำลอง (page.upstream) ที่ตอบ ในรูปที่ service จริงส่ง จากข้อมูล mock ชุดเดียวกับ replica Java — ถ้าพอร์ตผิด หน้าจะต่างจาก Java ทันที. scenario ที่ REST ทำไม่ได้ใส่ live: false; ที่ต้องเปลี่ยนที่อยู่/สถานการณ์ใส่ live: {code, hook}

ข้อจำกัดที่ต้องรู้

  • ยังไม่เคยตรวจกับ service จริง: UAT ต้อง Bearer ทุก endpoint, ไม่มี OpenAPI สาธารณะ และเรายังไม่มี test account. พิสูจน์ได้เพียง "ทำเหมือน servlet Java บน fixture ที่เขียนจากโค้ด Java" — ชื่อ field, envelope, paging ที่ fake สมมติอยู่ใน docs/integration/*-live.md ของแต่ละหน้า. ต้องทำ smoke test ด้วยบัญชีทดสอบจริง
  • PDF ของรายงาน / ใบรับเงิน (ReportPdfServlet, RvJasperReportServlet, RvReceiptPdfServlet): servlet ประกอบ SQL WHERE ใน URL แล้วเรียก Jasper server แยก (ไม่มี token). ให้ browser ทำเองไม่ได้ (ผู้ใช้แก้ SQL ใน URL ได้) — ต้องให้ backend เปิด REST endpoint; ตอนนี้แท็บที่เปิดแสดงข้อความว่ายังไม่เชื่อมระบบรายงาน
  • cache ใน session ของ servlet (จังหวัด, ประเทศ, master 30 นาที, enrich 120 วินาที) ไม่พอร์ต — เบราว์เซอร์ถามใหม่; filter state ที่ Java เก็บใน HttpSession เก็บใน sessionStorage ของแท็บ (ล้างตอน logout)
  • รูป http:// ของ file server: ไม่มี /docproxy สำหรับ <img> — โหลดตรง; ต้องเป็น https + CORS หรือให้ gateway ทำ proxy
  • งานที่ servlet ทำหลาย call ต่อเนื่องในเซิร์ฟเวอร์ (เช่นบันทึกใบรับเงิน 4 call) ตอนนี้ทำจากเบราว์เซอร์ จึงช้าลงตาม round trip
