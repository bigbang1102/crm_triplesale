หน้า /crm/schedule (pages/schedule.xhtml + components/work_modal.xhtml ที่ include ด้วย page=schedule) — 3 แท็บ: Calendar (รายปี / รายเดือน / รายสัปดาห์ / รายวัน เขียนเอง ไม่ใช้ FullCalendar, ตัวเลือกวันที่, ป๊อปอัป "อีก N รายการ", สวิตช์นัดหมาย/งานของมุมมองสัปดาห์และวัน), Board (kanban ของนัดหมายและของงาน ลากการ์ดข้ามคอลัมน์ = เปลี่ยนสถานะ, เลื่อนโหลดต่อรายคอลัมน์) และ List (ตารางนัดหมาย/ตารางงาน เลื่อนโหลดต่อรายตาราง) พร้อมเลือกผลิตภัณฑ์/กลุ่มขั้นตอน, เรียง, ค้นหา, กล่องตัวกรอง (ทีมขาย, ผู้รับผิดชอบ, สถานะ) ที่จำสถานะไว้ใน session และ work modal (ดู/เพิ่ม/แก้ไข — โหมดค้นหาลูกค้าเพราะหน้านี้ไม่มี lead ตายตัว). สร้างด้วย npm run schedule:sync = node tools/sync-schedule.mjs (+ tools/lib/work-modal.mjs; ต้องเพิ่ม script นี้ใน package.json ตอน merge — ดู INTEGRATION.md) — ห้ามแก้ไฟล์ที่สร้าง ให้แก้สคริปต์แล้วรันใหม่ (swap ที่ไม่ตรงกับต้นฉบับ = สคริปต์หยุด)
